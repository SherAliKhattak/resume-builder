# Resume Builder

A free, fully offline Flutter app for building an ATS-friendly resume on Android and iOS. Enter your details once, optionally paste a job description, pick a template, and export a PDF.

## Features

- Profile sections for personal info, summary, experience, education, skills, projects, and more
- Autosave to local SQLite (no account or server)
- Optional job-description keyword match
- Ten resume templates
- PDF preview, share, and JSON backup/restore
- Import from an existing PDF or DOCX

## Stack

Flutter, dart, flutter_bloc, Drift, pdf/printing, get_it, and go_router.

## Run

```bash
flutter pub get
flutter run
```

Requires Flutter 3.38 or later.
